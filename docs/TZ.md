# Техническое задание

- Разработать расширение VS Code на TypeScript с `strict` и минимальной версией VS Code `^1.85`.
- Переводить выделенный русский идентификатор или слово под каждым курсором на английский.
- Поддержать разбиение составных имён и стили camelCase, snake_case, PascalCase и UPPER_SNAKE_CASE.
- Определять вид имени эвристически, предоставить QuickPick для принудительного выбора.
- Получать кандидатов через MyMemory и резервный Google endpoint; задаваемый таймаут, прогресс и переключение при ошибке.
- Валидировать результат и заменять все цели одной транзакцией редактора.
- Предоставить настройки, горячую клавишу, контекстную команду и unit-тесты логики.
