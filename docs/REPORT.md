# Черновик отчёта по лабораторной работе №3

## Тема

Создание плагина.

## Среда и архитектура

**Плагин написан для VS Code.** Расширения подключают сторонние возможности к редактору через Extension Host — отдельную среду выполнения, изолирующую расширения от ядра пользовательского интерфейса. Манифест `package.json` объявляет совместимую версию VS Code в `engines`, точки активации в `activationEvents`, команды, клавиатурные сочетания, меню и настройки в `contributes`.

VS Code предоставляет Extension API: `vscode.commands` регистрирует команды, `vscode.window` показывает QuickPick и прогресс, `vscode.workspace` читает конфигурацию, а `TextEditor.edit` применяет изменения документа. Экспортируемая функция `activate` создаёт компоненты и регистрирует команды; `deactivate` предназначена для освобождения ресурсов при завершении жизненного цикла расширения.

## Реализация

RuIdentifier Translator переводит русские идентификаторы через цепочку MyMemory и Google endpoint. Код разделён на модули выделения, разбиения имени, определения вида, форматирования, валидации, провайдеров перевода и UI. Используются массивы для этапов обработки, `Map` для реестра сервисов и уникальных целей, `Set` для ключевых слов и интерфейс `TranslationProvider` для смены стратегии. ИИ помог подготовить код плагина, тесты, документацию и текст отчёта.

## Проверка

Юнит-тесты чистой логики находятся в `tests/core.test.ts`. Результаты и сценарии фиксируются после фактического запуска `npm test`; демонстрационные скриншоты необходимо добавить самостоятельно.
